# 单元格数据结构定义

Speed Sheet 底层基于 Yjs CRDT 数据模型构建，摒弃了老旧表格方案臃肿的内部状态。为了便于已有业务数据平滑对接，Speed Sheet 在中转转换层与单元格属性定义上，兼容了常见的通用单元格字段规范（参考 Luckysheet / Excel 标准）。

---

## 单元格属性表 (Cell Attributes)

每个单元格在底层映射为一个属性字典（`CellAttributes`），常用属性定义如下：

| 属性 Key | 类型 Type | 默认值 | 说明与示例 |
| :--- | :--- | :---: | :--- |
| **`v`** | `string \| number \| boolean` | - | **原始值 / 真实值 (Raw Value)**<br>如数值 `100`、布尔值 `true`、文本 `'Speed'`，日期格式下通常存储为时间戳或天数差值。 |
| **`m`** | `string \| number` | - | **渲染显示值 (Display Value)**<br>经过格式化计算后最终在画布上呈现的字符串，如 `'100.00%'`、`'2026-10-23'`、`'¥1,200.00'`。 |
| **`ct`** | `object` | - | **单元格类型与数字格式 (Cell Type)**<br>• `fa`: 格式化规则字符串，如 `'General'`、`'yyyy-MM-dd'`、`'0.00%'`；<br>• `t`: 数据类型缩写（`'n'` 数值、`'s'` 字符串、`'d'` 日期、`'g'` 常规）。 |
| **`f`** | `string` | - | **公式字符串 (Formula)**<br>以 `=` 开头的计算公式，如 `"=SUM(A1:B10)"`、`"=AVERAGE(C1:C5)"`。 |
| **`bg`** | `string` | - | **背景颜色**<br>支持 16 进制颜色或 RGBA，如 `'#1890ff'`、`'rgba(240, 245, 255, 0.8)'`。 |
| **`fc`** | `string` | - | **文字字体颜色**<br>如 `'#333333'`、`'#ff4d4f'`。 |
| **`ff`** | `number \| string` | `0` | **字体系列 (Font Family)**<br>`0`: 微软雅黑 / 苹方, `1`: 宋体, `2`: 黑体, `3`: 楷体, 或直接指定英文字体名。 |
| **`fs`** | `number` | `11` | **字体字号 (Font Size)**<br>单位为 pt，如 `10`, `11`, `14`, `18`。 |
| **`bl`** | `0 \| 1` | `0` | **加粗 (Bold)**：`1` 为加粗，`0` 为常规。 |
| **`it`** | `0 \| 1` | `0` | **斜体 (Italic)**：`1` 为斜体，`0` 为常规。 |
| **`cl`** | `0 \| 1` | `0` | **删除线 (Cancelline)**：`1` 为添加删除线。 |
| **`un`** | `0 \| 1` | `0` | **下划线 (Underline)**：`1` 为添加单下划线。 |
| **`ht`** | `0 \| 1 \| 2` | `1` | **水平对齐方式**：`0` 居中, `1` 左对齐, `2` 右对齐。 |
| **`vt`** | `0 \| 1 \| 2` | `0` | **垂直对齐方式**：`0` 垂直居中, `1` 靠上对齐, `2` 靠下对齐。 |
| **`tb`** | `0 \| 1 \| 2` | `0` | **文本换行处理**：`0` 截断, `1` 溢出, `2` 自动换行。 |
| **`tr`** | `0 \| 1 \| 2` | `0` | **文字旋转方式**：`0` 常规无旋转, `1` 向上倾斜45°, `2` 向下倾斜45°。 |
| **`mc`** | `object` | - | **合并单元格坐标**：<br>`{ r: 0, c: 0, rs: 2, cs: 2 }`<br>• `r`, `c`: 合并区域左上角起始坐标；<br>• `rs`, `cs`: 跨越的行数 (rowspan) 与跨越的列数 (colspan)。 |
| **`ps`** | `object` | - | **单元格批注 / 便签**：<br>`{ value: '批注说明内容', isShow: false }`。 |

---

## 常见格式示例

### 1. 百分比格式单元格
```json
{
  "v": 0.85,
  "m": "85.00%",
  "ct": {
    "fa": "0.00%",
    "t": "n"
  }
}
```

### 2. 日期格式单元格
```json
{
  "v": 44127,
  "m": "2020-10-23",
  "ct": {
    "fa": "yyyy-MM-dd",
    "t": "d"
  }
}
```

### 3. 公式单元格
```json
{
  "v": 350,
  "m": "350",
  "f": "=SUM(A1:A5)"
}
```
