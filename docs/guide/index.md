# 基本介绍

**Speed Sheet** 是一款面向现代化 Web 应用的轻量在线电子表格引擎。

底层彻底摒弃了老旧表格方案臃肿的内部状态与全局变量设计，基于 **Canvas 视口渲染**、**Yjs CRDT 协同状态** 与 **声明式命令扩展** 重新构建；同时在上层提供对常见 Luckysheet 数据结构的**兼容中转能力**，方便已有业务数据无缝衔接。

---

## 核心设计与解决的痛点

1. **摒弃老旧表格架构，拥抱现代数据流**：
   * 老旧表格往往把渲染、全局状态和 DOM 事件深度揉杂在一起，缺乏现代组件化生命周期管理。
   * **Speed Sheet 解法**：底层基于清晰的 Headless 视口计算与 Yjs 数据流，纯 Canvas 渲染；上层仅作为兼容中转层，支持无缝导入导出老格式数据。

2. **开箱即用的多人实时协同**：
   * 传统表格需要自己设计复杂的差量冲突解决机制，协同开发门槛极高。
   * **Speed Sheet 解法**：底层基于成熟的 Yjs (CRDT) 体系，所有单元格写入统一由事务调度，天然具备高可靠的多人并发协作能力。

3. **开箱统一组件，无需业务适配两套代码**：
   * 很多前端组件库过度拆包，单机用一个包、协同又要换另一个包。
   * **Speed Sheet 解法**：统一对外暴露一个 `<SpeedSheet />` 组件，单人模式、多人协同、只读查看仅需传参切换，业务调用极简。

---

## 核心技术栈

* **渲染层**：自研纯 Canvas 高性能视口按需重绘与事件调度
* **协同层**：Yjs CRDT 状态驱动
* **公式引擎**：常用计算函数支持（SUM、IF、VLOOKUP 等）
* **UI 展现**：Ant Design Vue 规范适配工具栏与弹层
