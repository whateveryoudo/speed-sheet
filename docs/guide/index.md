# 基本介绍

**Speed Sheet** 是一款面向现代化 Web 应用的轻量在线电子表格引擎。

底层彻底摒弃了传统开源表格庞大的全局变量与全量二维密集矩阵设计，基于 **平铺化稀疏存储**、**Canvas 视口按需动态调度** 与 **Yjs CRDT 协同数据流** 重新构建；同时在上层保留对 Luckysheet 常见数据结构的**兼容中转能力**，让老业务数据既能无缝接入，又能摆脱老旧表格的状态包袱。

---

## 核心设计与解决的痛点

1. **摒弃全量二维矩阵与全局单例包袱**：
   * 传统开源表格重度依赖庞大的二维密集数组与不可变全局状态，不仅容易带来内存碎片与冗余，也极难进行现代化组件生命周期封装。
   * **Speed Sheet 解法**：底层采用**平铺化稀疏结构**，天然契合分布式 CRDT 协同事务；仅对可见视口进行动态重绘调度，极大减轻内存占用与计算负担；对外则提供透明的中转转换，兼顾兼容性与现代性能。

2. **开箱即用的多人实时协同**：
   * 传统表格需要自己设计复杂的差量冲突解决机制，协同开发门槛极高。
   * **Speed Sheet 解法**：底层基于成熟的 Yjs (CRDT) 体系，所有单元格写入统一由事务调度，天然具备高可靠的多人并发协作能力。

3. **开箱统一组件，无需业务适配两套代码**：
   * 很多前端组件库过度拆包，单机用一个包、协同又要换另一个包。
   * **Speed Sheet 解法**：统一对外暴露一个 `<SpeedSheet />` 组件，单人模式、多人协同、只读查看仅需传参切换，业务调用极简。

---

## 核心技术栈

* **渲染层**：自研纯 Canvas 高性能视口按需重绘与事件调度
* **协同层**：Yjs CRDT 状态驱动
* **公式引擎**：常用计算函数支持（SUM、IF、VLOOKUP 等）
* **UI 展现**：Ant Design Vue 规范适配工具栏与弹层
